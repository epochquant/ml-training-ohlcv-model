# Claude Code Guidelines

Read and strictly adhere to @AGENTS.md.

Before starting any implementation:
1. Read `@docs/knowledge/SCRATCHPAD.md` for active context and next steps.
2. Read `@docs/knowledge/experiments_log.md` to avoid repeating past failed experiments.
3. Review `@docs/knowledge/kronos_architecture.md` and `@docs/knowledge/high_volatility_adaptations.md`.

At the end of a session:
1. Summarize achievements and update `@docs/knowledge/SCRATCHPAD.md`.
2. If an experiment was run, log the findings in `@docs/knowledge/experiments_log.md`.
